# rea-uber-gap-analysis (agent skill)

A lawful, REA-guided competitive-architecture gap-analysis workflow for AI coding agents.
Turns a shipped reference app's decompiled source into **verified, implementation-ready
knowledge** for your own app — without tripping provider safety flags and without violating
the reference app's rights.

- See `rea-uber-gap-analysis/SKILL.md`.
- Anti-flag framing, legal/IP discipline (port shapes/semantics, never proprietary code),
  a claims-ledger verification loop, and count-as-floor honesty.

**Install:** copy `rea-uber-gap-analysis/` into your agent's skills directory
(e.g. `~/.agents/skills/`).
